# ☀ 태양 관측소 (Ⅶ. 태양계 1-2: 태양과 태양 활동)

태양의 **표면**(광구·쌀알무늬·흑점)과 **대기**(채층·코로나·홍염·플레어)를 관측하고, **흑점 수 변화**와 **태양 활동이 지구에 미치는 영향**을 찾는 수업 자료예요.
학습지 1-2(5~7쪽), 교과서 232~237쪽, 수업 PPT 「태양(2025)」 내용만 써요.

> 같은 시리즈: 태양계 탐사대 · 일주운동 · 연주운동 · 달의 위상과 같은 화면 구성(수업 모드 / 탐사 모드 / 교사용)이고, 결과는 같은 구글 시트의 **'태양 현황'** 탭에 모여요.
> 이 차시는 공간 모형보다 "보고 구분하는" 내용이라 3D 대신 2D 관측 화면을 써요. (three.js를 불러오지 않아 가벼워요)

## 관측 화면

| 보기 | 보여 주는 것 |
|---|---|
| ☀ 광구 | 둥근 태양과 흑점. **태양을 누르면 온도**를 재요 (광구 약 6000℃, 흑점 약 4000℃ · 주변보다 약 2000℃ 낮음). ▶ 8일 동안 관측(처음 / 4일 후 / 8일 후)으로 흑점이 동 → 서로 옮겨 가는 것(태양의 자전), 🌐 경선·위선, 👣 처음 위치(점선). 화면의 **동쪽·서쪽은 "지구에서 볼 때"** 방향이라고 적어 두었어요 |
| 🧭 자전 방향 | 태양의 북극 위에서 내려다본 그림. 태양과 지구가 모두 시계 반대 방향(지구의 자전: 서 → 동)으로 돌고, 지구에서는 태양의 앞면이 동쪽 → 서쪽으로 지나가서 흑점이 동 → 서로 움직여 보인다는 것을 보여 줘요 (지구의 자전 방향과 헷갈리지 않게) |
| 🔍 확대 · ✂ 단면 | 확대하면 쌀알무늬 속 흑점(그림이 먼저, ✂ 단면은 눌러서). 단면은 광구 아래 대류 고리 — 고온 기체가 올라오는 곳은 밝고, 저온 기체가 내려가는 곳은 어두워요 |
| 🌑 개기 일식 | 달이 태양을 오른쪽부터 가려요(슬라이더·재생). 광구가 완전히 가려지면 채층(붉은색)·코로나(진주색)·홍염이 보여요. 태양 활동을 바꾸면 코로나 크기가 달라져요 |
| 🔥 홍염·플레어 | 태양 가장자리 확대. 홍염(고리·불꽃 모양)이 솟아오르고, 💥 플레어는 흑점 부근에서 채층 일부가 매우 밝아져요. 활발할 때는 홍염이 더 많고 플레어가 저절로 자주 일어나요 |
| 📈 흑점 수 변화 | 학습지 탐구 그래프 모양(1986~2024). 끌어서 연도를 바꾸면 오른쪽에 그해 태양 모습. A(극대기)·B(극소기) 표시, 📏 주기 재기(약 11년) |
| 🌍 지구에 미치는 영향 | 태양풍과 지구 자기장, 오로라. 활발할 때는 태양풍이 강해지고 자기장이 흔들려요. 영향 버튼(자기 폭풍·오로라·무선 통신 장애(델린저)·인공위성·정전·항공)을 누르면 교과서 그림 5의 설명이 나와요 |

애니메이션은 모두 **빠르기**(🐢 느리게 / 보통 / 빠르게)를 바꿀 수 있어요.

### 첫 화면 · 배경 · 소리

- **첫 화면 그림**: 흑점이 동 → 서로 지나가는 광구, 숨 쉬듯 일렁이는 코로나와 홍염, 7초마다 번쩍이는 플레어, 지구 자기장 앞에서 휘어지는 태양풍, 극지방의 오로라를 한 장에 그린 움직이는 장면이에요.
- **배경**: 검은색 대신 오른쪽 위의 햇빛, 왼쪽 아래의 푸른 성운, 작은 별, 태양을 둘러싼 궤도선이 깔린 우주 배경이에요. 패널은 살짝 비쳐 보여요.
- **배경음악**: 음악 파일 없이 브라우저가 직접 연주해요(저작권 걱정 없음, 인터넷 없어도 됨).
  - 처음·수업·임무 화면: 잔잔한 우주 음악
  - 게임 1단계: 경쾌한 곡
  - 게임 2단계 상황실: 긴장감 있는 곡. 흑점이 많아질수록 빨라지고 촘촘해져요.
  - 게임에서 정답·오답, 플레어, 🛡 대비 효과음이 나요.
  - 오른쪽 아래 🎵 버튼으로 켜고 끄며(🔇), 설정은 기기마다 기억해요. 브라우저 규칙 때문에 화면을 한 번 누른 뒤부터 소리가 나요.
  - 교실에서 여러 태블릿으로 할 때는 이어폰을 쓰거나 🎵 버튼으로 꺼 두세요.

## 🧑‍🚀 탐사 모드 (학생 태블릿용)

1. **임무 1. 태양의 표면**: 광구·흑점 온도 재기, 8일 동안 흑점 이동 관측, 확대 → 단면 보기 → 보고서 7문제
2. **임무 2. 태양의 대기**: "개기 일식 때 무엇이 보일까?" **예측** → 개기 일식 만들기, 홍염·플레어 일으키기 → 카드 6장(흑점·쌀알무늬·채층·코로나·홍염·플레어)을 **표면 / 대기 / 대기에서 나타나는 현상**으로 분류 → 7문제
3. **임무 3. 태양 활동과 지구**: "활발해지면 태양풍은?" **예측**(예측 뒤에도 흑점 수 그래프가 그대로 보여요) → 그래프에서 극대기·극소기 찾기, 지구 보기에서 활발할 때로 바꾸고 영향 4개 이상 눌러 보기 → 8문제 (주기 11년, A·B 비교, 태양풍, 자기 폭풍, 델린저 현상, 오로라, 2013년 예보 → 2024년)
4. **임무 4. 확인 퀴즈**: 짧은 지문으로 핵심 개념을 확인하는 13문제 (모든 학생 같은 문제). 겹치는 내용은 한 문제씩만 남겼어요: 흑점 이름·온도, 쌀알무늬의 원인, 흑점 이동(자전), 대기를 보는 때(개기 일식), 채층·홍염·코로나 구분, 채층 < 코로나 온도, 플레어, 홍염, 표면에서 보이는 것, 극대기, 코로나 크기 비교, 태양 활동과 지구. 그림 문제는 실제 사진(흑점·쌀알무늬, 채층·홍염·코로나, 4일 간격 흑점 이동, 플레어, 다섯 장 사진, 1999·2017 일식, 오로라)과 흑점 수 그래프예요. 💡 태양 한눈에 정리 표를 펼쳐 볼 수 있어요.

5. **🎮 마지막 도전 · 태양 탐정** (임무 4를 마치면 열려요, 약 4~5분, 두 단계)
   - **1단계 이게 뭘까?** (6문제, 10초씩): 실제 사진의 일부가 크게 보이다가 점점 넓어져요. 빨리 맞힐수록 점수가 커요. 보기에 헷갈리는 짝(홍염·플레어, 채층·코로나)이 꼭 들어가요.
     - 6문제 중 2문제는 **"지금은 볼 수 없는 것"** 고르기예요. 개기 일식 사진에서는 흑점이나 쌀알무늬(달이 광구를 가려서), 평소 태양 사진에서는 코로나나 채층(광구가 너무 밝아서)이 정답이에요. 보이는 것을 고르면 "이 사진에서 보여요"라고 알려 줘요.
   - **2단계 우주 기상 상황실** (실시간 75초): 학생이 국가기상위성센터의 우주 기상 예보관이 돼요.
     - 위쪽 흑점 수 그래프가 2008년(극소기) → 2014년(극대기) → 2019년(극소기)로 흘러가고, 흑점 수가 많을수록 태양에 흑점이 늘고 코로나 빛이 커지며 💥 플레어가 자주 터져요. (극소기에는 거의 조용해요)
     - 플레어가 터지면 태양풍이 지구로 날아오고 경보가 떠요. 경보는 시설 이름 대신 피해 내용으로 나와요(예: "전파 신호 방해, 델린저 현상 주의!" → 📻 무선 통신). 3~4초 안에 📻 무선 통신 · 🛰 인공위성 · ⚡ 발전소 · ✈ 북극 항로 · 🧭 지구 자기장(자기 폭풍) 중 알맞은 곳의 🛡 대비를 눌러요. 경보 문구는 교과서 표현 그대로이고, 버튼 순서는 할 때마다 섞여요. 빨리 누를수록 점수가 커요(100~150점 + 연속 보너스).
     - 경보가 없는 곳에 대비를 켜면 헛 대비로 40점이 줄어요. 파란 📡 관측 소식(흑점 무리가 보여요, 홍염이 솟았어요 등)은 대비가 필요 없어요.
     - 중간에 질문이 세 번 와요: 🌌 오로라 여행사(지금 떠날까요?), 📰 과학 기자(개기 일식 때 코로나는 클까요?), 📺 방송국(흑점 수가 늘어나는 중? 줄어드는 중?). 그때의 흑점 수 그래프를 보고 대답해요 (+80점, 7초 안에, 보기 순서는 섞여요).
     - 끝나면 **방어율**(막은 태양풍 ÷ 날아온 태양풍)과 헛 대비·질문 대답 결과가 나와요. 이 단계에서는 목숨이 줄지 않아요.
   - 목숨 3개(1단계에서 틀리거나 시간이 지나면 하나씩), 2연속부터 연속 보너스(+20점씩, 최대 +100), 할 때마다 문제·보기 순서가 바뀌어요.
   - 게임 점수는 임무 성적과 따로 시트의 **'태양 게임 현황'** 탭에 모여요(최고 점수·도전 횟수·마지막 점수·끝까지 통과·최고 방어율).
   - 교사 화면 아래에 **🛡 반 대항 지구 방어율**(2단계 상황실까지 간 학생들의 최고 방어율 평균, 1~3위 메달과 막대)과 **반별 최고 점수** 표가 나와요. 반을 누르면 그 반 학생별 점수·방어율 순위가 보여요. 1단계에서 목숨을 다 써서 상황실에 못 간 학생은 방어율 평균에서 빠져요.

- 정답 자리는 첫 번째에 몰리지 않게 정해진 차례로 섞었어요 (모든 학생 같은 순서). 숫자·연도·ㄱㄴㄷ 조합 보기는 차례대로 둬요.

- 관측 체크는 예측을 맞힌 뒤부터 세요. 화면을 바꿀 때 저절로 솟는 홍염은 체크로 치지 않아요.
- "약 6000℃ / 4000℃ / 2000℃", "약 11년"은 학습지 빈칸 내용이라 문항에 넣었어요. 코로나 "100만 ℃ 이상"은 교과서에 있어서 정리 카드·한눈에 정리에만 넣고 문항에는 넣지 않았어요. 핵 1500만 ℃(PPT에만 있음)는 넣지 않았어요.
- 교사 화면에서 반별 완료 인원, "한 번에 맞힌 수", 틀린 답(분류에서 잘못 고른 칸, 예측에서 고른 답)을 볼 수 있어요.
